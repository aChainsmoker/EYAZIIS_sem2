# Лабораторная №9

Приложение работает с выбранным документом на русском или английском языке. Streamlit предоставляет чат, запись голосовых команд и страницы поиска, реферирования, перевода и озвучки. Отдельный процесс watchdog синхронизирует каталог с PostgreSQL и S3 (MinIO).

## Подготовка

Используйте Python 3.11 на Windows. Откройте PowerShell в корне проекта и подготовьте окружение.

```powershell
cd E:\Docs\eyaziis_2sem\eyaziis_sem2_lab9
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m nltk.downloader stopwords wordnet punkt_tab
.\.venv\Scripts\python.exe -m src.translation.prepare
```

Команда подготовки Argos устанавливает модели EN→RU и RU→EN. Уже установленное направление пропускается. Для первоначальной установки моделей нужен интернет. Whisper загружает `small` при первом использовании. Для озвучки установите голоса Windows SAPI для русского и английского языков.

Определитель языка использует встроенные JSON-профили и стандартный Python. Английский частотный профиль перенесён из лабораторной №2. Русский профиль содержит 300 наиболее частых записей из списка FrequencyWords, состоящих только из русских букв. Числовые веса сохраняют опубликованное число вхождений в корпус OpenSubtitles 2018. Веса каждого профиля нормируются на их сумму. Оценка языка равна сумме весов слов с учётом количества вхождений в документ. При равных или нулевых оценках результатом становится `unknown`.

Источник русского профиля — Hermit Dave, [FrequencyWords, ru_50k.txt](https://github.com/hermitdave/FrequencyWords/blob/525f9b560de45753a5ea01069454e72e9aa541c6/content/2018/ru/ru_50k.txt), версия `525f9b560de45753a5ea01069454e72e9aa541c6`. Раздел `ru` в `profiles.json` является адаптацией этих данных и распространяется по [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Выполненные преобразования включают отбор первых 300 записей из русских букв и перевод в формат JSON. Условия использования данных указаны в [README FrequencyWords](https://github.com/hermitdave/FrequencyWords#license). Качество определения языка на пользовательском корпусе ещё предстоит оценить.

Настройки подключения находятся в `config.toml`, исключённом из Git. Для нового экземпляра скопируйте `config.example.toml`. Путь наблюдения задаётся в `catalog.directory`. Параметры BM25 находятся в `search`, параметры реферирования — в `summary`, путь FFmpeg — в `whisper.ffmpeg_path`.

В секции `[tts.voices]` можно задать отдельные ID голосов через ключи `ru` и `en`. Пустое значение выбирает первый доступный голос соответствующего языка. Для английского также поддерживается прежний ключ `tts.voice_id`. Темп обычный, громкость 100%.

## Запуск

Запустите Docker Desktop, затем выполните команду запуска PostgreSQL и MinIO.

```powershell
.\.venv\Scripts\python.exe run_storage.py
```

Дождитесь готовности контейнеров. В первом терминале запустите индексатор и оставьте его работать.

```powershell
.\.venv\Scripts\python.exe -m src.indexer
```

Индексатор создаёт bucket и выполняет миграцию служебных таблиц. После обновления приложения он автоматически определяет язык и перестраивает старые записи индекса, включая файлы с прежним хешем. Дождитесь сообщения о завершении сверки. Во время обновления команды для ещё не обработанных документов возвращают сообщение об ожидании индексации.

Во втором терминале из корня проекта запустите Streamlit.

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Откройте `http://localhost:8501`. Порты хранилищ заданы в Docker Compose. PostgreSQL доступен на 5459, MinIO на 9010, консоль MinIO на 9011.

## Работа с документом

1. Добавьте документы TXT, PDF, DOCX или RTF в `data/incoming` либо в папку из TOML. Обрабатываются также вложенные папки. TXT поддерживает UTF-8 и UTF-16 с BOM. PDF должен содержать текстовый слой.
2. На странице «Чат» выберите документ из списка. В списке указаны название и определённый язык. Совпадающие названия и языки различаются номером документа. Первоначальный выбор выполняется пользователем.
3. Напишите команду в строке ввода внизу чата. Над ней закреплён раскрывающийся блок «Голосовое сообщение». Для записи выберите язык речи в боковом меню, раскройте блок, нажмите микрофон, произнесите команду, остановите запись и нажмите «Отправить голосовое сообщение». Нижняя панель использует `st.bottom`, доступный в установленной версии Streamlit 1.67.
4. После выполнения команды нажмите «Открыть…» в ответе бота для перехода к результату. Реферат можно скачать как PDF, озвучку прослушать и скачать как WAV.
5. Для смены документа вернитесь в чат. При возвращении к уже обработанному файлу восстанавливаются его результаты, поисковый запрос, `k1`, `b`, язык перевода и коэффициенты реферирования. История сохраняет название документа для каждого сообщения. Кнопки «Открыть…» доступны для актуального сохранённого результата выбранного документа.

```text
Найди в тексте "поисковая фраза"
Сделай реферирование документа
Переведи документ на русский
Переведи документ на английский
Озвучь документ
```

Английские варианты команд работают с тем же выбранным документом.

```text
Find in the text "search phrase"
Summarize the document
Translate the document to Russian
Translate the document to English
Read aloud the document
```

Поисковая фраза обрабатывается на языке документа. Все действия используют оригинал выбранного файла. При переводе на исходный язык показывается оригинальный текст с пояснением.

Выбор сохраняется при переходах между страницами. На каждой странице действия показан текущий документ и его сохранённый результат. Для повторного действия можно использовать её форму или кнопку. Новый успешный расчёт заменяет результат этого действия для выбранного документа. При ошибке предыдущий успешный результат остаётся доступен. Для документов без сохранённых результатов используются настройки TOML и начальные значения форм.

Если индексатор изменит содержимое или исходный язык файла, очищаются результаты соответствующего документа. При чтении каталога удаляется кеш отсутствующих файлов. Если удалён выбранный документ, приложение предлагает повторный выбор. Проверка после длительного расчёта защищает от сохранения результата изменившегося документа.

При языке `unknown` сервис возвращает объяснение, что метод частотных слов не определил язык. При отсутствии модели Argos или подходящего голоса SAPI интерфейс показывает соответствующее сообщение.

Запись выполняется микрофоном браузера. Для локальной работы используйте `localhost`. При доступе с другого компьютера браузеру для записи нужен HTTPS.

## Сервисы и хранение

```python
from src.bot.models import Command
from src.bot.parser import parse_command
from src.bot.service import execute, handle_message, handle_audio

# ID берётся из каталога.
document_id = 1
command = parse_command('Найди в тексте "пример"')
result = execute(command, document_id)
result = handle_message('Сделай реферирование документа', document_id)
result = execute(Command('translation', target_language='en'), document_id)
# result = handle_audio(audio_bytes, language='ru', document_id=document_id)
```

`Command` содержит `action`, поисковый `argument` и `target_language`. Для реферирования и озвучки аргумент пустой. Контракты выполнения принимают ID выбранного документа явно.

`BotResult` содержит `success`, `action`, `page`, `message`, `data` и `error_code`. В успешном результате `data.document` включает ID, название, путь, исходный язык и хеш файла. Поле `page` задаёт переход на `search`, `summary`, `translation` или `speech`.

- Поиск возвращает `query` и `results` с оценкой BM25, позициями и подсвеченным фрагментом выбранного документа. Формула из №1 использует нормализованный TF, `IDF=log10(N/df)`, `k1=1.2` и `b=0.75`. Частоты и средняя длина рассчитываются по актуальному индексу документов соответствующего языка. Русский использует SnowballStemmer, английский — WordNetLemmatizer.
- Реферирование сохраняет Sentence Extraction и TextRank из №3 с начальными весами 0,7/0,3 из TOML. На странице реферирования доступны два ползунка от 0 до 1 с шагом 0,05. Их сумма должна равняться 1. После изменения весов нажмите «Составить реферат». До повторного расчёта сохранённый реферат доступен с пояснением о различии коэффициентов. Выбранные веса сохраняются в сессии и применяются также к текстовым и голосовым командам чата. По умолчанию возвращаются до 10 предложений, 15 ключевых слов, текст и PDF в байтах. Фактически использованные веса и число предложений доступны в `data.parameters`. Реферат создаётся на языке оригинала. Частоты берутся по коллекции того же языка.
- Перевод возвращает `text`, `source_language` и `target_language`. Модели Argos кешируются отдельно для каждого направления.
- Озвучка возвращает `audio` в байтах, `mime_type` и `filename`. Голос SAPI соответствует языку оригинала. Длинный текст делится на фрагменты, совместимые WAV объединяются.
- Голосовой ввод дополнительно возвращает `data.recognized_text`. Whisper обрабатывает полную завершённую запись.

Оригиналы хранятся в S3. Метаданные находятся в шести полях `documents`. Поисковые данные находятся в `search_documents`, `terms` и `inverted_index`. Версия обработки хранится в `search_documents`, а ключ термина включает язык. Миграция выполняется репозиторием при запуске индексатора.

Рефераты, переводы, PDF, WAV и история чата хранятся в памяти сессии. Кеш организован как `bot_results[document_id][action]`. Для каждого документа сохраняется по одному успешному результату каждого действия вместе с ID записи, хешем, исходным языком и параметрами расчёта. При первом обращении после обновления успешные результаты прежней структуры сессии автоматически переносятся в новый кеш с сохранением ID для истории чата. Для старых рефератов коэффициенты берутся из текущего состояния сессии. Результаты скачиваются до завершения сессии. Временные файлы SAPI удаляются после чтения.

Новые коды ошибок включают `language_unknown` и `document_not_ready`. Проверка работоспособности запуском и тестирование выполняются по отдельному указанию пользователя.
