# Методы распознавания

## Метод частотных слов

**Поисковый образ языка (ПОЯ)** — это набор слов, обладающих наибольшей частотой встречаемости в документах обучающего корпуса (ТОП-300 слов).

### Алгоритм:

1. Из тренировочного корпуса для каждого языка извлекаются все слова и считается их частота
2. Формируется множество ТОП-300 самых частых слов — это ПОЯ языка
3. Для входного документа также формируется ТОП-300 частых слов
4. Языком считается тот, чей ПОЯ имеет **максимальное пересечение** с ТОП-300 документа

---

## Метод коротких слов

**ПОЯ** — набор лексем длиной **не более 5 символов**, встретившихся в обучающем корпусе **более 3 раз**, с рассчитанными вероятностями.

### Алгоритм:

1. Из тренировочного корпуса извлекаются короткие слова (≤ 5 символов)
2. Для каждого слова рассчитывается вероятность: `P(слово) = частота / сумма_частот_всех_коротких_слов`
3. Входной документ разбивается на лексемы
4. Лексемам, присутствующим в ПОЯ, назначаются их вероятности; отсутствующим — минимальная вероятность
5. Вероятность принадлежности предложения языку = **произведение вероятностей его лексем** (на практике — сумма логарифмов, чтобы избежать переполнения)

---

## Нейросетевой метод

**ПОЯ** — обученная нейронная сеть (MLP), принимающая на вход символьные N-граммы текста.

### Алгоритм:

1. Тренировочный корпус нарезается на фрагменты по 200 символов, каждому присваивается метка языка
2. Фрагменты векторизуются через **character N-граммы (2–4)** с помощью `CountVectorizer`
3. На полученных векторах обучается многослойный перцептрон (`MLPClassifier` из `scikit-learn`)
4. Входной документ векторизуется тем же способом и подаётся на вход сети
5. Сеть выдаёт предсказание языка
