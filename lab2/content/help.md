# Справка по системе

## 1. О системе

Система предназначена для **автоматического распознавания языка** текстовых документов формата PDF. Поддерживаются два языка: **испанский** и **английский**. Для каждого документа применяется три независимых метода распознавания, а итоговый язык определяется голосованием большинства.

---

## 2. Словарь терминов

### Основные понятия распознавания

| Термин | Расшифровка |
|--------|-------------|
| **ПОЯ** | **Поисковый образ языка** — формализованное описание языка, построенное на основе тренировочного корпуса (набор частых слов, вероятности коротких слов или обученная нейросеть). |
| **ПОД** | **Поисковый образ документа** — формализованное описание входного (анализируемого) документа, построенное по тем же правилам, что и ПОЯ. |
| **Тренировочный корпус** | Набор текстов на известном языке (20–120 Кб), на основе которого строится ПОЯ. В данной системе хранится в папке `train_data/`. |
| **Лексема** | Отдельное слово, полученное после разбиения текста. |
| **Голосование большинства** | Стратегия принятия решения: если два из трёх методов назвали один и тот же язык — он и считается итоговым. |

### Методы распознавания

| Термин | Расшифровка |
|--------|-------------|
| **Метод частотных слов** | Метод, в котором ПОЯ — это ТОП-300 самых частых слов языка. Документ относится к языку, чей ПОЯ имеет наибольшее пересечение с ТОП-300 слов документа. |
| **Метод коротких слов** | Метод, в котором ПОЯ — набор слов длиной ≤ 5 символов с рассчитанными вероятностями. Язык определяется как произведение (сумма логарифмов) вероятностей лексем документа. |
| **Нейросетевой метод** | Метод, в котором ПОЯ — обученная нейронная сеть (MLP), принимающая на вход символьные N-граммы текста. |
| **N-грамма** | Подстрока текста длиной N символов. Например, для слова «hola» 2-граммы: `ho`, `ol`, `la`; 3-граммы: `hol`, `ola`. |
| **Character N-грамма** | N-грамма, построенная по символам (а не по словам). Используется в нейросетевом методе с диапазоном 2–4. |
| **Векторизация** | Преобразование текста в числовой вектор. В системе применяется `CountVectorizer` из `scikit-learn`, считающий количество вхождений каждой N-граммы. |
| **MLP (Многослойный перцептрон)** | Тип искусственной нейронной сети прямого распространения. В системе используется `MLPClassifier` из `scikit-learn`. |
| **Вероятность лексемы** | Отношение частоты слова к сумме частот всех коротких слов в тренировочном корпусе. |
| **Минимальная вероятность** | Очень малое число (10¹⁰), назначаемое словам, которых нет в ПОЯ, чтобы избежать нулевого произведения. |
| **Сумма логарифмов** | Математический приём: вместо перемножения вероятностей (что приводит к переполнению) складывают их логарифмы. Чем больше сумма — тем выше вероятность принадлежности языку. |

### Архитектура и компоненты системы

| Термин | Расшифровка |
|--------|-------------|
| **MVC** | **Model-View-Controller** — архитектурный паттерн, разделяющий приложение на три слоя: данные (Model), интерфейс (View) и логику обработки (Controller). |
| **Model** | Слой данных: извлечение текста из PDF, реализация трёх методов распознавания, хранение профилей языков. Файл: `model.py`. |
| **View** | Слой представления: веб-интерфейс на Streamlit, отображение таблиц, кнопок, графиков. Файл: `app.py`. |
| **Controller** | Слой управления: принимает действия пользователя из View, вызывает методы Model и БД, возвращает готовые данные. Файл: `controller.py`. |
| **Watcher (Наблюдатель)** | Фоновый сервис, который каждые 3 секунды проверяет синхронизированную папку на наличие новых PDF и автоматически их анализирует. Файл: `watcher.py`. |
| **MySQL** | Реляционная система управления базами данных, в которой хранятся результаты анализа и частоты слов. |
| **Статус `processed`** | Документ успешно проанализирован всеми тремя методами. |
| **Статус `pending`** | Документ обнаружен, но ещё не обработан. |
| **Статус `error`** | При анализе документа произошла ошибка. |

## 3. Описание методов распознавания

###  Метод частотных слов
1. Из тренировочного корпуса для каждого языка извлекаются все слова и считается их частота.
2. Формируется **ТОП-300** самых частых слов — это ПОЯ языка.
3. Для входного документа также формируется ТОП-300 частых слов (ПОД).
4. Языком считается тот, чей ПОЯ имеет **максимальное пересечение** с ПОД.

### Метод коротких слов (≤ 5 символов)
1. Из тренировочного корпуса извлекаются короткие слова, встретившиеся **более 3 раз**.
2. Для каждого слова рассчитывается **вероятность**: `P(слово) = частота / сумма_частот_всех_коротких_слов`.
3. Входной документ разбивается на лексемы.
4. Лексемам из ПОЯ назначаются их вероятности, остальным — минимальная вероятность (10⁻¹⁰).
5. Итоговая вероятность = **сумма логарифмов** вероятностей всех лексем. Язык с большей суммой — победитель.

### Нейросетевой метод
1. Тренировочный корпус нарезается на фрагменты по **200 символов**, каждому присваивается метка языка.
2. Фрагменты векторизуются через **character N-граммы (2–4)** с помощью `CountVectorizer`.
3. На полученных векторах обучается **MLPClassifier** (нейросеть с тремя скрытыми слоями).
4. Входной документ векторизуется тем же способом и подаётся на вход сети.
5. Сеть выдаёт предсказание языка.

## 4. Описание функционала интерфейса

###  Вкладки

| Элемент | Назначение |
|---------|-----------|
| **Помощь** | Текущая страница — справка по системе, словарь терминов, описание методов и функционала. |
| ** Анализ текстов** | Основная рабочая вкладка: загрузка документов, просмотр результатов, детальный анализ, статистика, экспорт и печать. |

###  Загрузка документов

| Элемент | Назначение |
|---------|-----------|
| **Загрузка через интерфейс** | Блок для ручной загрузки PDF-файла через браузер. |
| **Выберите PDF-документ** | Кнопка-загрузчик. Открывает диалог выбора файла на компьютере. После выбора файл автоматически сохраняется в папку `synced_folder/` и анализируется тремя методами. |
| **Файл ... успешно обработан!** | Зелёное уведомление, появляющееся после успешного анализа загруженного файла. |

### Синхронизированная папка

| Элемент | Назначение |
|---------|-----------|
| **Синхронизированная папка** | Информационный блок, показывающий абсолютный путь к папке `synced_folder/`. |
| **Фоновый наблюдатель** | Автоматически (каждые 3 секунды) сканирует папку `synced_folder/`. Любой новый PDF-файл, помещённый туда, будет автоматически проанализирован и сохранён в базу данных. |
| ** Статус обработки файлов из папки** | Раскрывающийся блок (expander), показывающий таблицу со всеми файлами из папки синхронизации и их текущим статусом (`processed` / `pending` / `error`). |

###  Основная таблица результатов

| Элемент | Назначение |
|---------|-----------|
| **Сравнительная таблица результатов по методам** | Главная таблица системы. Каждая строка — документ, столбцы: имя файла, источник (`folder` / `frontend`), результат каждого из трёх методов, итоговый язык (по голосованию большинства), статус. |

### Детальный анализ выбранного документа

| Элемент                                      | Назначение |
|----------------------------------------------|-----------|
| **Выберите документ для детального анализа** | Выпадающий список (selectbox) со всеми документами из базы данных. Позволяет выбрать конкретный файл для глубокого разбора. |
| **0. Извлечено N символов текста**           | Зелёное уведомление, показывающее объём текста, извлечённого из PDF. Если текст не удалось извлечь (например, файл является сканом), появится красное сообщение об ошибке. |
| **1. Метод частотных слов**                  | Блок с двумя вкладками (Испанский / Английский). В каждой — таблица: слово, частота в обучающей выборке, частота в документе. Отсортирована по убыванию частоты в документе. Внизу — статистика: сколько слов из ПОЯ встретилось в документе. |
| **2. Метод коротких слов (≤5 символов)**     | Блок с двумя вкладками по языкам. Таблица: слово, вероятность в ПОЯ, назначенная вероятность (реально использованная в расчёте), частота в документе. Внизу — статистика и **сумма логарифмов** — ключевая метрика метода. |
| **3. Нейросетевой метод (N-граммы)**         | Таблица ТОП-50 наиболее частых character N-грамм (2–4 символа) в документе. Внизу — итоговое предсказание нейросети. |

###  Сравнительная статистика методов

| Элемент | Назначение |
|---------|-----------|

| **Столбчатая диаграмма** | Визуализация таблицы выше: наглядное сравнение методов по количеству распознанных документов. |

| **По источникам** | Разбивка документов по способу добавления: из папки синхронизации (`folder`) или через интерфейс (`frontend`). |

## 5. Инструкция по использованию

### Быстрый старт

1. **Подготовьте тренировочные данные** (если ещё не подготовлены):
   - Создайте папку `train_data/spanish/` и поместите туда испанские `.txt` или `.pdf` файлы (суммарно 20–120 Кб).
   - Создайте папку `train_data/english/` и поместите туда английские файлы.
   - Запустите `python train_model.py` — будет создана папка `trained_model/` с обученными профилями.

2. **Запустите приложение**:
   ```bash
   streamlit run app.py
